🎲 Okey Masası (Okey Scoreboard)

A super simple, single-file web app to track Okey scores with your friends. No need for pen and paper anymore!

✨ Features
* **Random Matchmaking:** Automatically assigns players to teams or tables.
* **Digital Scoreboard:** Calculates scores automatically (up to 10 rounds).
* **Works Offline:** Saves everything directly to your browser.
* **Dark Mode:** Perfect for late-night games.

🚀 How to Use
1. Download the `index.html` file.
2. Double-click to open it in your browser.
3. Add your friends' names and start playing!

*Tech Stack: No database, no backend, no installation. Built entirely in a single file using React, Tailwind CSS, and HTML5 LocalStorage.
